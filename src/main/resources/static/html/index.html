How It Works

Get Started in 3 Simple Steps

Whether you're a teacher or student, Smartshala makes it easy to get started.

1

Create Your Account

Sign up as a Teacher or Student in seconds. It's completely free to get started.

2

Create or Join a Class

Teachers create classes and share a unique code. Students join with the 6-character class code.

3

Start Live Learning
